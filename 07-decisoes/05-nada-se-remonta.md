# 05 · O estado muda o conteúdo, nunca o desenho

**O contexto.** Estados que remontavam a tela — o número pulando de lugar, a barra sumindo — faziam o estado parecer outra tela.

**A decisão.** Num estado, os blocos ficam onde estão e muda o que eles dizem.

**O que foi descartado.** Desenhar cada estado como uma tela própria.

**A consequência.** Todo estado é a tela-base com outro conteúdo; o prazo estourado da T14 é o exemplo.
