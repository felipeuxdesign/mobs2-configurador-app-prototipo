# As amostras do claro

São **26 telas desenhadas no claro**, pra conferir. **Não são referências oficiais**: a referência de cada tela continua sendo a da pasta dela, desenhada no escuro, e o claro nasce dos tokens. Estas imagens são o **gabarito** das regras do claro que dependem do lugar, como "este bloco é rebaixado, este quadradinho é poço".

**Como usar**: abra o protótipo no claro na mesma tela e compare com a amostra. Diferença de cor é erro de token ou de regra; diferença de forma não pode existir, porque a forma é a do escuro.
